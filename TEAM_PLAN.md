## Rules we agreed on

- Same Unity version for everyone: **6.5 (`6000.5.4f1`)**
- Work on your own branch, pull before you start, open a pull request into main
- Only one person in the scene file at a time — say so in Discord first
- If you're stuck for more than a day, say something instead of sitting on it
